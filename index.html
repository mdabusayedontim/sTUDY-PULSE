Under the hood

Your password is never stored

When you sign up, StudyPulse generates a random 16-byte salt and runs your password through PBKDF2-SHA256 with 150,000 iterations. Only the resulting hash is saved. Signing in re-derives the hash and compares it in constant time.

This is a fully client-side account system — perfect for personal use, classroom machines and static hosting. If you need cross-device sync, swap the Auth object for Firebase or Supabase.

  • Salted per user
  • 150,000 iterations
  • Constant-time compare
  • Session expiry
  • Isolated per-user data
